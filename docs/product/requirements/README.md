# Requirements Index

This directory indexes functional requirements from the [functional specification](functional-specification.md). As requirements are implemented, they are traced to GitHub Issues and PRs.

## Structure

Requirements are organized by the specification's sections:

- **REQ-AUTH** — Authoring (§7)
- **REQ-NAV** — Structure and Navigation (§8)
- **REQ-VER** — Versioning and Publication (§9)
- **REQ-VIEW** — Audience Views and Distribution (§10)
- **REQ-DEV** — Developer Handoff (§11)
- **REQ-API** — API and MCP (§12)
- **REQ-MIG** — Migration (§13)
- **REQ-FDN** — Foundations (§16–19)
- **REQ-SEC** — Security, Authentication and Authorisation (§17)

## Traceability Format

```
REQ-XXX-NNN: Short description
- Issue: #NNN
- PR: #NNN
- Release: RX
- Status: Not Started | In Progress | Implemented | Verified
```

Requirements will be populated as the implementation progresses. No requirements are implemented yet (pre-R0).
