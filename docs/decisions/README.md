## Two things to watch, neither of them a pending decision

**D14 is conditional.** [ADR-0023](../adr/0023-rich-text-editor.md), as amended 2026-08-17, uses **MDXEditor** — chosen partly because its canonical form **is** Markdown, which materially de-risks the one Must requirement (Markdown as the **stored** form with a lossless round-trip). A time-boxed spike must still settle the round-trip for the full block set before M1.5 begins; the fallback (TipTap or Lexical) is named in the ADR so that the spike is a decision point rather than a sunk cost.

**D13 was taken twice.** Next.js was accepted first, then reversed the same day: [ADR-0007](../adr/0007-api-as-single-entry-point.md) forbids both Server Component data reads and Server Actions, which left the framework adopted under a permanent restriction on its two defining features — a rule contradicted by every tutorial about it, in a codebase written largely by agents. Vite has no such path to restrain. The reasoning is kept in [ADR-0022](../adr/0022-application-framework.md) because it is also the reasoning that would justify going back: deploying to Vercel, needing SSR or SEO, or deciding to weaken ADR-0007 from _single entry point_ to _single validation pipeline_.
